# FEMDOM RUSH

개인용 캐릭터형 하이브리드 타워 디펜스 프로젝트.

## 핵심 방향
- **Kingdom Rush**식 고정 경로, 웨이브, 처치 골드, 전투 중 업그레이드
- **Arknights**식 캐릭터 배치, 방향, 저지(Block), DP, SP 스킬, 재배치
- 건물 타워 대신 **여성 캐릭터 유닛**을 배치
- 맵의 배치 가능 지점은 별도 건축 에셋 대신 **반투명/점선 타원 슬롯**으로 표시
- 그래픽·사운드·몬스터·타일·오브젝트·UI는 기존 **Alix1211/ARPG** 자산을 최대한 재사용
- Google Drive `FEMDOMRUSH` 폴더에 개인 세이브/플레이 로그를 자동 저장하는 구조를 목표로 함

## 설계 문서
1. `docs/01_UI_DESIGN.md` — 전투 HUD와 배치/업그레이드/결과 UI
2. `docs/02_MAPS_V01.md` — 초기 게임판 3종
3. `docs/03_CORE_SYSTEM.md` — 전투, 경제, 클래스, 웨이브, 난이도, 세이브/로그

## v0.1 목표
먼저 3개 맵으로 **배치 → 방향 선택 → 저지 → 전투 → 스킬 → 업그레이드 → 조기 웨이브 호출 → 결과**의 전체 루프를 완성한다. 재미가 검증되면 동일 시스템을 기반으로 스테이지 데이터를 확장한다.
