# 01. UI 설계 — FEMDOM RUSH v0.1

## 1. 화면 기준

- 기준 해상도: **1920×1080 가로형**
- 실제 기기에서는 비율 유지 스케일링. HUD는 화면 가장자리 safe-area 기준.
- 전투 화면의 주인공은 맵과 캐릭터다. UI 패널은 가능한 한 작고, ARPG의 기존 장식 프레임을 필요한 만큼만 사용한다.
- 배치 지점은 별도 건축대 에셋을 만들지 않는다. **길 주변의 반투명 타원/점선 타원**으로만 표시한다.
- 평상시에는 배치 지점을 거의 숨기고, 유닛 카드를 선택했을 때만 유효 슬롯을 밝힌다.

## 2. 전투 HUD 배치

### 상단 좌측 — 기지 상태
- ❤️ 라이프
- 현재 스테이지 번호/이름
- 보스 스테이지일 경우 작은 보스 마크

권장 영역: 화면 x=2~18%, y=2~10%.

### 상단 중앙 — 웨이브
- `WAVE 3 / 7`
- 현재 웨이브 진행 바
- 다음 웨이브 적 종류 미리보기 2~3종
- **조기 호출 버튼**: 다음 웨이브까지 5초 이상 남았을 때만 활성화
- 조기 호출 보너스 골드와 SP 보너스를 버튼 바로 아래에 작은 숫자로 표시

권장 영역: x=34~66%, y=2~11%.

### 상단 우측 — 속도/메뉴
- 일시정지
- 1× / 2× 전투속도
- 설정
- 사운드 on/off는 설정창 안으로 넣고 HUD에서는 제거

권장 영역: x=82~98%, y=2~10%.

### 하단 중앙 — 출전 유닛 카드
기본 8칸.

각 카드 표시:
- 얼굴/직업 이미지
- DP 배치 비용
- 현재 배치 여부
- 재배치 쿨다운
- 배치 가능 시 테두리 점등
- DP 부족 시 어둡게
- 이미 배치된 유닛은 카드 상단에 작은 `ON FIELD`

권장 영역: x=18~82%, y=86~99%.

### 하단 좌측 — DP
- 큰 숫자로 현재 DP
- 작은 자동회복 게이지
- DP 생산형 유닛 스킬 발동 시 짧은 +숫자 애니메이션

권장 영역: x=2~17%, y=88~98%.

### 하단 우측 — Gold
- 현재 Gold
- 선택된 캐릭터 업그레이드 가능 시 작은 화살표 점멸
- Gold는 **배치 비용이 아니라 전투 중 업그레이드 비용**에 사용

권장 영역: x=83~98%, y=88~98%.

## 3. 배치 조작

### 3-1. 유닛 선택
1. 하단 유닛 카드 탭.
2. 해당 유닛이 배치 가능한 모든 타원 슬롯만 표시.
3. 불가능한 슬롯은 표시하지 않거나 25% 투명도로 비활성 표시.
4. 사거리 미리보기는 카드 선택 상태에서 유효 슬롯을 탭했을 때만 표시.

### 3-2. 슬롯 선택
- 빈 슬롯: 흰색 점선 타원.
- 현재 선택 유닛 배치 가능: 밝은 금빛 반투명 타원.
- 근접/저지 슬롯: 타원이 길과 살짝 겹치게 배치.
- 원거리 슬롯: 길 바깥쪽에 배치.
- 특수 슬롯: 작은 보라색/청색 중심점만 추가. 별도 대형 장식은 사용하지 않는다.

### 3-3. 방향 선택
슬롯을 탭하면 캐릭터 실루엣과 **4방향 화살표 링**이 뜬다.

- 위 / 아래 / 좌 / 우 네 방향
- 방향을 탭하면 즉시 배치
- 배치 전 해당 방향의 실제 공격 범위를 반투명 부채꼴/직사각형으로 표시
- 취소는 캐릭터 바깥 영역 탭 또는 X 버튼

명일방주의 방향 개념은 가져오되, 그리드 전체를 노출하지 않고 **고정 타원 슬롯 + 4방향**으로 단순화한다.

## 4. 배치 후 유닛 선택 UI

전장 캐릭터를 탭하면 화면 오른쪽 하단에 작은 캐릭터 패널이 열린다.

표시 항목:
- 이름 / 클래스 / 현재 Lv
- HP
- ATK / DEF / RES
- 저지 수(Block)
- 공격 범위
- SP 게이지
- 스킬 버튼
- 업그레이드 버튼
- 퇴각 버튼

### 업그레이드
- `Lv1 → Lv2 → Lv3 → 특화 A/B`
- 골드 사용
- 업그레이드 전 증가 수치를 간단히 표시: `ATK +18 / 사거리 +8%`
- 최종 특화 선택 후 되돌리기 없음. 한 판 종료 후 초기화.

### 스킬
- SP 충전 전: 어둡게 + 숫자
- 충전 완료: 지속 점멸
- 수동 스킬: 탭 발동
- 자동 스킬은 카드에 `AUTO` 표기
- 스킬 지속 중에는 SP 게이지를 잠금 상태로 표시

### 퇴각
- 한 번 탭 → `퇴각?` 확인
- 배치 DP 일부 환급
- 카드에 재배치 쿨다운 표시

## 5. 적 정보 UI

적을 탭하면 아주 작은 정보 말풍선만 표시한다.

- 이름
- HP 바
- 방어: 낮음/보통/높음
- 마법 저항: 낮음/보통/높음
- 특징 아이콘: 비행 / 회복 / 원거리 / 빠름 / 보스

정확한 방어 숫자는 상세 도감에서만 보여준다. 전투 중에는 상성 판단이 즉시 가능해야 한다.

## 6. 조기 웨이브 호출

화면 상단 중앙의 웨이브 버튼을 탭하면 즉시 호출.

버튼 안 표시:
- `+35G`
- `SP +5`
- 남은 시간

호출 시:
- 짧은 경고음
- 입구 화살표 점멸
- 다음 웨이브 적 아이콘 표시
- 현재 스킬 지속 중인 유닛은 SP 보너스를 받지 않는 규칙을 UI에 작은 잠금 아이콘으로 표시

## 7. 스테이지 시작 전 화면

한 화면에서 끝낸다.

왼쪽:
- 스테이지 맵 미리보기
- 입구/출구 수
- 추천 위험도

오른쪽:
- 출전 유닛 8명
- 사용 가능한 전체 로스터
- 드래그 또는 탭 교체

하단:
- 시작
- 이전
- 다음
- 기록

적 미리보기:
- 처음 만난 적은 `???`
- 이미 만난 적은 타입/방어 특성 표시

## 8. 결과 화면

성공:
- 별 1~3
- 남은 라이프
- 클리어 시간
- 조기 호출 횟수
- 누출 적 수
- 사용 Gold
- MVP 유닛
- `다음 스테이지` / `재도전`

실패:
- 어느 웨이브에서 무너졌는지
- 가장 많이 통과한 적 타입
- `재도전`을 가장 크게 표시

## 9. 장기 메뉴

필수만 구현:
- 스테이지 선택
- 로스터
- 영구 업그레이드
- 도감
- 설정

상점/가챠/유료재화는 만들지 않는다.

## 10. ARPG 자산 재사용 계획

### 그대로 재사용
- `assets/ui/kit_a/*`
- `assets/ui/kit_b/*`
- `assets/ui/kit_c/*`
- `assets/ui/hud/*`, `hud_clean/*`
- `assets/ui/hud_icons/*`
- `assets/ui/bar_*.png`
- `assets/bgm/*`
- 기존 효과음/스킬 아이콘

### 새로 필요한 UI 그래픽
사실상 없음. 필요 시 CSS/Canvas로 생성:
- 배치 점선 타원
- 사거리 반투명 영역
- 방향 선택 화살표 링
- 웨이브 진행선
- 재배치 쿨다운 마스크

## 11. 입력 원칙

- 모든 핵심 조작은 한 손가락 탭으로 가능.
- 드래그는 선택 사항이며 탭 대체 수단을 항상 제공.
- 유닛 카드 → 슬롯 → 방향의 **3탭 배치**를 기본.
- 이미 배치한 유닛은 캐릭터 탭 → 스킬/업그레이드.
- 전투 도중 전체 화면을 가리는 창은 사용하지 않는다.

## v0.1 UI 완료 조건

1. 카드 선택 시 배치 가능한 타원 슬롯이 나타난다.
2. 슬롯 선택 시 방향과 사거리가 표시된다.
3. 배치 후 적을 자동 공격한다.
4. 유닛 탭으로 스킬/업그레이드/퇴각이 가능하다.
5. DP, Gold, 라이프, 웨이브가 실시간 갱신된다.
6. 조기 웨이브 호출이 작동한다.
7. 승리/패배 결과가 한 화면에 정리된다.
