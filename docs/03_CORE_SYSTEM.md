# 03. 핵심 시스템 설계 — FEMDOM RUSH v0.1

이 문서는 `하이브리드 타워 디펜스 게임 기획`과 `킹덤 러시 시스템 분석`을 바탕으로 FEMDOM RUSH에 맞게 단순화한 **구현 기준서**다.

---

# 1. 게임의 한 줄 정의

**고정 경로를 따라 몰려오는 적을 여성 캐릭터 유닛으로 막고, DP로 배치하며 Gold로 전투 중 강화하고, 방향·저지·SP 스킬·조기 웨이브 호출을 이용해 짧고 빠르게 깨는 캐릭터형 타워 디펜스.**

목표 플레이 길이:
- 일반 스테이지: 90~150초
- 보스 스테이지: 150~210초
- 100스테이지 전체는 짧은 반복 플레이 중심

---

# 2. 한 판의 전체 흐름

1. 스테이지 선택
2. 출전 유닛 8명 편성
3. 전투 시작
4. 초기 DP/Gold 지급
5. 유닛 배치
6. 방향 선택
7. 자동 전투 + 수동 스킬
8. 적 처치로 Gold 획득
9. Gold로 현장 업그레이드
10. 필요 시 퇴각/재배치
11. 조기 웨이브 호출로 Gold + SP 보너스
12. 최종 웨이브/보스
13. 결과 기록
14. Google Drive 세이브 + 플레이 로그 자동 저장

---

# 3. 자원 시스템

## 3-1. DP — 배치력

용도:
- 유닛 최초 배치
- 퇴각 후 재배치

v0.1 기본값:
- 초기 DP: **12**
- 자연 회복: **1 DP / 1초**
- 최대치: **99**
- 유닛 배치비용: 대략 8~30
- DP 생산형 유닛/스킬 존재

DP는 캐릭터를 얼마나 빨리 전장에 올릴 수 있는지를 조절한다.

## 3-2. Gold — 강화 재화

획득:
- 적 처치
- 정예/보스 보상
- 조기 웨이브 호출

사용:
- 배치된 유닛 Lv 업
- 최종 특화 A/B 선택
- 일부 스킬 해금

v0.1 기본:
- 초기 Gold: **150**
- 약한 적: 3~5G
- 중형 적: 7~12G
- 강적: 15~30G
- 정예: 30~60G
- 보스: 스테이지 종료 보상 처리

**DP와 Gold의 역할은 섞지 않는다.**

# 4. 전투 피해 공식

## 물리 피해

```
damage = max(ATK - DEF, ceil(ATK * 0.05))
```

- 방어력이 높아도 최소 5% 피해 보장.
- 빠른 연타형과 고화력 저속형의 차이를 만들기 쉬움.

## 마법 피해

```
damage = floor(ATK * (1 - RES))
```

- RES는 0.00~0.90.
- 예: RES 0.40이면 마법 피해 40% 감소.

## 폭발 피해

```
damage = max(ATK - DEF * 0.5, ceil(ATK * 0.05))
```

- 물리 방어력의 절반만 적용.
- 다수 적 처리에 강하지만 기본 공격속도는 느리게.

## 고정 피해

```
damage = ATK
```

- DEF/RES 무시.
- 희귀 스킬이나 궁극기에만 제한적으로 사용.

# 6. 배치 시스템

## 고정 슬롯 방식

명일방주식 전체 그리드를 그대로 쓰지 않는다.

FEMDOM RUSH는:
- 길 주변에 **고정 배치 슬롯**
- 화면에는 **반투명 타원/점선 타원**
- 유닛 선택 시에만 슬롯 표시
- 슬롯 데이터로 근접/원거리/특수 구분

장점:
- 맵 제작이 빠름
- 모바일에서 오작동 적음
- 배경 미관을 해치지 않음
- 경로와 전투 밸런스를 직접 통제 가능

## 배치 방향

4방향:
- Up
- Down
- Left
- Right

방향은 공격 범위와 타겟 가능 영역을 바꾼다.

근접 유닛은 방향 영향이 작고,
궁수/마법사/창병은 방향 영향이 크게 느껴지도록 한다.

---

# 7. 저지(Block)

적이 근접 유닛의 저지 범위에 진입하면 이동을 멈추고 교전한다.

기본 저지 수 예시:
- 뱅가드/창병: 2
- 기사: 3
- 드워프 중전사: 2
- 암살자: 1
- 궁수/마법사: 0

규칙:
- 저지 수만큼 적을 동시에 정지.
- 초과 적은 통과.
- 비행 적은 기본적으로 저지 불가.
- 보스는 `blockWeight` 값을 가져 일부 저지 유닛을 무시 가능.

---

# 8. 기본 타겟팅

모든 일반 원거리 유닛의 기본 우선순위:

1. 사거리 내
2. 공격 가능한 타입
3. **출구까지 가장 가까운 적**
4. 동률이면 먼저 진입한 적

특화 유닛은 필터를 바꿀 수 있다.

예:
- 궁수 특화: 비행 우선
- 저격 특화: 고DEF 또는 고HP 우선
- 마녀: 가장 많은 적이 뭉친 지점 우선
- 드래곤: 정예/보스 우선

수동 일점사 지정은 v0.1에서는 넣지 않는다.

---

# 9. 클래스 8종

초기 로스터는 캐릭터 외형이 아니라 **역할** 기준으로 먼저 완성한다.

## 1) 선봉 창병
- 비용: 8 DP
- 저지: 2
- 물리
- 중거리 찌르기
- 스킬: DP 즉시 +6
- 역할: 초반 전선 + 경제

## 2) 기사
- 비용: 14 DP
- 저지: 3
- 높은 DEF/HP
- 역할: 병목 유지
- 스킬: 일정 시간 방어력 상승 + 자가회복

## 3) 궁수
- 비용: 12 DP
- 저지: 0
- 빠른 물리 원거리
- 공중 공격 가능
- 역할: 잡몹/비행 처리

## 4) 마법사
- 비용: 18 DP
- 저지: 0
- 느린 고화력 마법
- 역할: 중장갑 처리

## 5) 드워프 해머
- 비용: 17 DP
- 저지: 2
- 짧은 범위 광역 물리/폭발
- 낮은 공격속도
- 스킬: 지진 스턴

## 6) 드래곤 전사
- 비용: 28 DP
- 저지: 2
- 고비용 만능형
- 화염 범위 + 공중 대응
- 역할: 후반 캐리
- 밸런스상 재배치 쿨 길게

## 7) 마녀/저주술사
- 비용: 20 DP
- 저지: 0
- 마법 + 슬로우/방어 약화
- 역할: 지원/CC

## 8) 쾌속 암살자/하피
- 비용: 10 DP
- 저지: 1
- 짧은 재배치 쿨
- 역할: 새는 적 처리, 원거리 적 암살, 긴급 투입

이 8역할에 현재 보유 여성 캐릭터/팸몬 에셋을 매칭한다.

# 10. 현장 업그레이드

모든 유닛은 한 판 안에서 초기화되는 현장 업그레이드를 갖는다.

단계:
- Lv1: 배치 기본 상태
- Lv2: 기본 스탯 강화
- Lv3: 역할 강화
- 특화 A / 특화 B: 최종 분기

예: 궁수
- Lv2: 공속 +15%
- Lv3: 사거리 +10%
- A: 연사/독/속박
- B: 저격/고DEF 우선/큰 한방

예: 기사
- A: 탱커 — DEF, 회복, 저지 강화
- B: 공격기사 — 공격력/반격/범위베기

v0.1의 MAP01에서는 Lv1~3만 노출.
MAP03부터 최종 특화 분기 시험.

---

# 11. SP 스킬

SP 회복 모드 3종:
- AUTO: 시간에 따라 회복
- ATTACK: 공격할 때 회복
- DEFENSE: 피격 시 회복

v0.1 기본:
- AUTO: 1 SP/초
- ATTACK: 타격당 1 SP
- DEFENSE: 피격당 1 SP

스킬 상태:
- CHARGING
- READY
- ACTIVE
- COOLDOWN/LOCK

**스킬이 ACTIVE인 동안 SP는 회복하지 않는다.**

수동 스킬은 READY 상태에서 유저가 직접 누른다.

---

# 12. 조기 웨이브 호출

다음 웨이브 타이머가 남아 있을 때 호출 버튼 활성화.

보상 예시:
```
bonusGold = min(60, remainingSeconds * 4)
bonusSP = min(10, ceil(remainingSeconds / 2))
```

SP 보너스:
- CHARGING 유닛만 획득
- ACTIVE/READY 락 상태 유닛은 획득하지 않음

목적:
- 잘하는 플레이어가 위험을 감수하고 더 빠르게 성장
- 게임 템포를 플레이어가 직접 조절

---

# 13. 퇴각/재배치

기본값:
- 최초 퇴각 DP 환급: 원래 비용의 50%
- 재배치 쿨: 12초
- 2번째 배치 비용: 기본의 1.5배
- 3번째 이후: 기본의 2배

쾌속 유닛:
- 재배치 쿨 6초
- 비용 상승 완화

이 수치는 v0.1 로그를 보고 조정.

# 14. 상태 이상

v0.1에 필요한 것만 구현.

- Slow: 이동속도 감소
- Stun: 이동/공격 정지
- Bind: 이동 정지, 공격 가능
- Silence: 특수 능력 사용 금지
- Burn/Poison: 지속 피해

적이 `statusResist=true`면 상태이상 지속시간 50% 감소.

Freeze, Levitate, 복잡한 원소 게이지는 v0.2 이후.

# 15. 밀치기 / 무게

적은 `weight` 0~5.
스킬은 `force` 0~5.

단순화 규칙:

```
delta = force - weight
delta <= 0  : 이동 없음
delta == 1 : 짧게 밀림
delta == 2 : 중간 밀림
delta >= 3 : 크게 밀림
```

MAP03의 구덩이와 연동.

보스는 기본 weight=5 또는 shiftImmune.

---

# 16. 적 역할군

ARPG 몬스터를 아래 역할로 재분류한다.

1. **Swarm** — 슬라임, 고블린
2. **Armored** — 오크/중장형
3. **Fast** — 늑대/토끼형
4. **Flying** — 가고일/하피
5. **Healer** — 샤먼/마법사형
6. **Ranged** — 궁수/마법사
7. **Tank** — 오우거/대형
8. **Elite** — 강화 개체
9. **Boss**

몬스터 외형과 실제 전투 역할은 데이터로 분리한다.

# 19. 영구 성장

과도하게 복잡하게 만들지 않는다.

스테이지 별을 사용해 계정 전체 강화.

카테고리:
- DP 초기 +1
- Gold 초기 +10
- 근접 HP +3%
- 원거리 ATK +3%
- SP 회복 +3%
- 조기호출 보너스 +5%

각 항목 5단계 제한.

유닛 개별 레벨업/장비 파밍은 v0.1에서는 제외.
필요하면 이후 추가.

# 20. 난이도 적응 시스템

이 게임은 개인용이므로 **플레이어 1명의 실제 로그에 맞춰 난이도를 조정**한다.

게임이 스스로 모든 걸 실시간으로 바꾸는 구조보다,
스테이지 종료 시 플레이 성능을 기록하고 다음 스테이지의 보정치에 천천히 반영한다.

## 플레이어 레이팅

`playerRating` 시작값: 100

예시 변화:
- 압승: +4
- 여유 승리: +2
- 아슬아슬 승리: 0
- 1회 실패 후 성공: -1
- 연속 실패: -3

레이팅은 직접 적 HP를 크게 바꾸기보다 아래 항목을 조절한다.

- 적 수량: ±15%
- 정예 비율: ±10%
- 웨이브 간격: ±15%
- 적 조합 난이도
- 회복/공중/빠른 적의 혼합 비율

**보스 기본 스탯은 적응 난이도로 크게 흔들지 않는다.**

# 23. 경로 처리

v0.1은 고정 waypoint 방식.

- 맵 로드 때 path 배열 읽기
- 적은 waypoint index만 따라감
- 매 프레임 A* 금지
- 저지 상태에서는 이동 일시정지
- 슬롯이 경로를 막아도 우회로를 새로 만들지 않는다

따라서 복잡한 동적 길찾기는 필요 없다.

향후 다중 경로 선택이 필요할 때만 flow-field/A* 추가.
